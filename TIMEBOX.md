# Timebox

1. **Prise en main (~1h)** : lecture de l'énoncé et des données, compréhension du
   métier, découverte de Nest et Nuxt que je n'avais jamais utilisés, installation.
2. **Conception (~1h)** : le modèle (déclarations et corrections stockées à part,
   arbre de travail calculé, versions figées), avant d'écrire du code.
3. **Code (~2h)** : d'abord le domaine et ses tests, puis le module Nest et les trois
   pages Nuxt.
4. **Compréhension et analyse (~1h)** : relecture du code généré par Claude Code, pour
   vérifier la cohérence et faire des parallèles avec ce que je connais
   de React et Express.
5. **Rédaction (~1h)** : README et page de synthèse.

**Bilan** : j'ai dépassé le temps prévu (environ 6h au lieu de 4), surtout à cause de la
découverte de Nest et Nuxt et du temps passé à comprendre le code généré. J'ai coupé le diff
entre versions et la validation des entrées de l'API.
J'ai committé par phase en fin de session plutôt qu'au fil de l'eau.
